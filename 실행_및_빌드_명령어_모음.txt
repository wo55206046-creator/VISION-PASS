================================================================================
  [VISION-PASS] 서버 실행, 동기화 및 안드로이드 APK 빌드 명령어 모음
================================================================================

자주 사용하는 명령어와 생성된 APK 파일 위치를 모아두었습니다. 
복사(Ctrl+C) 후 터미널(PowerShell)에 붙여넣기(Ctrl+V 또는 마우스 우클릭)하여 사용하세요.


--------------------------------------------------------------------------------
0. [추천] 로컬에서 수정사항 즉시 실시간 확인하기 (0.1초 즉시 반영)
--------------------------------------------------------------------------------
▶ 간편 실행 방법:
   폴더 내의 '로컬_실시간_미리보기.bat' 파일을 더블 클릭하시면
   브라우저(http://localhost:3000)가 자동으로 열리며,
   코드 수정 내용이 0.1초 만에 화면에 즉각 실시간으로 반영됩니다!

▶ 터미널 명령어:
npm run dev


--------------------------------------------------------------------------------
1. 로컬 개발 서버 실행 (PC 웹 브라우저에서 작업 및 테스트)
--------------------------------------------------------------------------------
명령어:
npm.cmd run dev

▶ 브라우저 접속 주소: http://localhost:3000
▶ 종료 방법: 터미널에서 Ctrl + C 누른 후 Y 입력


--------------------------------------------------------------------------------
2. 코드 수정 후 안드로이드 앱으로 최신 내용 동기화 (가장 자주 사용)
--------------------------------------------------------------------------------
명령어:
npm.cmd run android:sync

▶ 기능: 웹 코드를 정적 빌드(out/)하고 안드로이드 앱(android/)에 최신 상태로 덮어씁니다.


--------------------------------------------------------------------------------
3. Android Studio 열기 (APK 파일 추출)
--------------------------------------------------------------------------------
명령어:
npx.cmd cap open android

▶ APK 생성 방법 (Android Studio 실행 후):
  상단 메뉴 [Build] ➔ [Build Bundle(s) / APK(s)] ➔ [Build APK(s)] 클릭
  ➔ 완료 후 우측 하단 팝업의 [locate] 글자 클릭하면 파일 위치가 바로 열립니다!


--------------------------------------------------------------------------------
★ 생성된 APK 파일 저장 위치 (스마트폰에 전송할 파일)
--------------------------------------------------------------------------------
▶ 상대 경로:
   android\app\build\outputs\apk\debug\app-debug.apk

▶ 전체 절대 경로 (Windows 탐색기 주소창에 복사해서 바로 이동 가능):
   C:\Users\USER\Desktop\VISION-PASS\android\app\build\outputs\apk\debug

※ 스마트폰 전송 방법:
   위 경로에 있는 'app-debug.apk' 파일을 카카오톡(나에게 보내기), 구글 드라이브,
   또는 USB 케이블을 통해 스마트폰으로 보내서 설치하시면 됩니다.


--------------------------------------------------------------------------------
4. [최초 1회만 실행] 안드로이드 폴더 생성 (android 폴더가 없을 때만)
--------------------------------------------------------------------------------
명령어:
npx.cmd cap add android


--------------------------------------------------------------------------------
5. [가장 간편한 방법] 명령어 입력 없이 마우스 더블 클릭으로 실행하기
--------------------------------------------------------------------------------
▶ 원클릭 APK 빌드: 
   폴더 내의 'build-apk.bat' 파일을 더블 클릭하여 실행

▶ 서버 없이 브라우저 단독 실행:
   폴더 내의 'index.html' 파일을 더블 클릭하여 크롬/엣지에서 바로 실행


--------------------------------------------------------------------------------
6. [GitHub 호스팅] 웹 사이트 무료 배포 및 업데이트
--------------------------------------------------------------------------------
▶ 원클릭 자동 배포:
   폴더 내의 'github-upload.bat' 파일을 더블 클릭하여 실행

▶ 명령어 직접 실행:
   git add .
   git commit -m "Update"
   git push origin main

★ GitHub Pages 활성화 (저장소 생성 후 최초 1회만):
   1. GitHub 저장소(Repository) 페이지 이동
   2. 상단 [Settings] 탭 ➔ 좌측 [Pages] 메뉴 클릭
   3. Build and deployment > Source 항목을 [GitHub Actions]로 변경
   4. 이후 푸시할 때마다 Actions 탭에서 자동 빌드 및 배포 완료!


================================================================================
* 팁: Windows PowerShell에서 스크립트 실행 오류가 발생할 때는 아래 명령어를 1회 실행하세요:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
